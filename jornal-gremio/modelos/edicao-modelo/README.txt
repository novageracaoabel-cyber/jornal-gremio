MODELO DE EDIÇÃO

1. Copie a pasta inteira para edicoes/edicao-002 (use o próximo número).
2. Edite edicao.json.
3. Troque capa.svg por uma capa própria e atualize o campo "capa" no JSON.
4. Copie materia-modelo.md para cada nova matéria dentro de materias/.
5. Coloque imagens das matérias dentro de materias/ e preencha o campo imagem.
6. Não apague edicao.json nem os campos obrigatórios.
